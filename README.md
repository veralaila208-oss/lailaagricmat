# AgroSim Dual - Simulador Educativo Agrícola

Estructura de archivos del proyecto:
- index.html : Estructura semántica y componentes visuales (Tailwind CSS).
- styles.css : Reglas de estilo personalizadas y animaciones.
- app.js     : Motor numérico, Canvas 2D interactivo, gráficas y gestión dual (Estudiante/Docente).

Para ejecutar: Abre 'index.html' directamente en cualquier navegador web moderno.
